# AP4: Non-Linear Systems 

## Description
This practical assignment aims to solve systems of non-linear equations and analyze the convergence rates of different iterative methods.

## Implemented Methods
*   **Successive Approximations (Fixed-Point Iteration):** Applied with a Gauss-Seidel approach.
*   **Newton's Method for Systems:** Standard implementation using the Jacobian matrix.
*   **Modified Newton's Method:** Evaluates the Jacobian only at the initial approximation to reduce computational cost per iteration.
