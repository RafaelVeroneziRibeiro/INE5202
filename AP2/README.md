# AP2: Linear Systems 

## Description
This activity involves solving linear systems with a focus on computational efficiency and analyzing matrix conditioning.

## Key Topics
*   **Sparse/Tridiagonal Systems:** Implementation of an optimized Gaussian Elimination algorithm to solve heat distribution problems using only four vectors.
*   **Ill-Conditioned Systems:** Analysis of Hilbert matrices ($H_n$) to understand how small changes in coefficients affect the solution. LU factorization, condition number, and determinants were calculated to verify instability.
