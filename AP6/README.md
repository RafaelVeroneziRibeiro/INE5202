# AP6: Interpolation and Numerical Integration 

## Description
This activity covers approximating unknown functions and calculating definite integrals numerically.

## Implemented Methods
*   **Newton's Divided Differences:** Building an interpolation table to determine the coefficients of a 4th-degree Newton polynomial.
*   **Trapezoidal Rule:** A numerical integration algorithm to approximate definite integrals (e.g., calculating natural logarithms) by dividing the area into multiple subintervals.
