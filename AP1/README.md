# AP1: Algebraic Equations 

## Description
This assignment focuses on implementing numerical methods to find roots of algebraic and transcendental equations.

## Implemented Methods
*   **False Position Method:** Finds roots within a specific interval.
*   **Horner's Method:** Evaluates polynomials and their derivatives efficiently, reducing the number of required multiplications and additions.
*   **Newton's Method:** Standard implementation and a modified version to handle functions with multiple roots (where the derivative approaches zero).
