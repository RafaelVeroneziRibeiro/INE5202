# AP3: Iterative Methods for Linear Systems 

## Description
Implementation of iterative methods to solve large systems of linear equations. 

## Implemented Methods
*   **Gauss-Seidel Method:** Standard iterative technique.
*   **Successive Over-Relaxation (SOR):** An optimization of the Gauss-Seidel method. The program experimentally determines an optimal relaxation parameter to minimize the number of iterations required for convergence.
