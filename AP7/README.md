# AP7: Ordinary Differential Equations (ODEs) 

## Description
Implementation of numerical methods based on Taylor series to solve Initial Value Problems (IVPs) and systems of ODEs.

## Implemented Methods
*   **Runge-Kutta Family:**
    *   Euler Method (RK1).
    *   Improved Euler Method (RK2).
    *   Runge-Kutta 4th Order (RK4).
*   **Application (Lotka-Volterra):** The methods were used to simulate a predator-prey biological system, generating time-series plots and phase portraits for the populations.
