# AP5: Curve Fitting and Least Squares 

## Description
Application of the Least Squares Method to model astronomical data. The objective was to fit polar coordinate measurements of a comet to Kepler's Law of planetary motion.

## Implemented Methods
*   **Linearized Least Squares:** Transforming the non-linear equation into a linear form to find the parameters.
*   **Gauss-Newton Method:** Iterative method to solve the non-linear least squares problem directly.
