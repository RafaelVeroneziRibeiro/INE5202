# EP: Machine Learning & Linear Regression 

## Description
The final project of the course focuses on applying the Least Squares Method to solve Machine Learning problems. The goal was to minimize the cost function by solving the normal system of equations.

## Implemented Models
*   **Linear Regression with One Variable:** Predicting the profits of a food truck franchise based on city population data.
*   **Linear Regression with Multiple Variables:** Creating a model to predict housing prices based on features such as square footage and the number of bedrooms.
